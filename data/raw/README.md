# Raw Data

This folder stores the original operational files used for the analysis.

Raw files are excluded from version control due to confidentiality restrictions.

The original dataset included information such as:

- call attempts
- effective contacts
- non-contact records
- sales quantity
- operational time metrics
- supervisor information
- campaign information

## Version Control Policy

Files in this folder are intentionally ignored by Git using `.gitignore`.

*.xlsx
