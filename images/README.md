# Images

This folder is intended to store visual outputs from the analysis.

Recommended charts include:

- model comparison
- standardized variable impact
- sales vs talk time
- sales vs ACW
- actual sales vs predicted sales
- residual analysis

## Usage

Images stored here can be referenced in the main `README.md`, the Word report or the PowerPoint presentation.

## Current Status

If charts are generated from the notebook, they should be exported here as `.png` files.
